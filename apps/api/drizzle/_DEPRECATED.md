# DEPRECATED — Drizzle Migration Snapshots

These SQL files are **archived legacy snapshots** and must NOT be applied to any database.

## Source of Truth

**TypeORM is the sole migration executor for MUSIC OS 360.**

All schema changes must be made via TypeORM migration files in:
```
apps/api/src/database/migrations/
```

Running migrations:
```bash
pnpm --filter api db:migrate
```

## Why these files exist

These files were generated by `drizzle-kit generate` during an earlier phase of the project before the migration system was standardised on TypeORM. They are kept for historical reference only.

## DO NOT

- Run `drizzle-kit push` or `drizzle-kit migrate` against any environment
- Use these files as the basis for new schema changes
- Add new files to this directory

If you need to add a Drizzle-based introspection snapshot for documentation purposes, add it under `docs/schema-snapshots/` instead.
