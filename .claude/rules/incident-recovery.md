# Incident and Root-Cause Mode

Incident work follows: detect -> classify -> contain -> preserve evidence -> diagnose -> mitigate -> recover -> validate -> root cause -> prevention.

Containment and mitigation may be urgent but must still preserve a minimal audit trail. Never destroy evidence to make the system look healthy. Distinguish symptom recovery from root-cause resolution.

After repeated failure or a material incident, identify proximate cause, contributing factors, systemic cause, detection gap and prevention gap. Prefer deterministic controls/tests/observability improvements over adding another prose reminder.
