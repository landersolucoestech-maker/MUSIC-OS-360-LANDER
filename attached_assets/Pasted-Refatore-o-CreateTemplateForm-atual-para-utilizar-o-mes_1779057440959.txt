Refatore o CreateTemplateForm atual para utilizar o mesmo padrão visual e estrutural do editor fullscreen de templates já existente no sistema.

IMPORTANTE:
NÃO alterar a arquitetura principal do editor atual.
NÃO voltar para modal baseado em cláusulas.
NÃO recriar o sistema antigo.
Apenas evoluir o editor fullscreen existente.

OBJETIVO:
Transformar o fluxo de criação de templates em uma experiência semelhante ao Word/Google Docs, mantendo:
- editor fullscreen
- placeholders/variáveis
- preview visual
- suporte a cabeçalho e rodapé
- sidebar contextual

==================================================
ESTRUTURA GERAL
==================================================

A tela deve ser fullscreen.

Remover completamente:
- seção de cláusulas separadas
- cards de cláusulas
- textarea por cláusula
- upload de header/footer dentro do formulário principal
- modal scrollável antigo

O editor deve ser o centro da experiência.

==================================================
TOPBAR DO EDITOR
==================================================

Criar uma topbar fixa no topo contendo:

ESQUERDA:
- botão voltar
- nome do template editável inline

DIREITA:
- botão "Variáveis"
- botão "Documento"
- botão "IA"
- botão "Salvar"

Layout moderno e limpo.

Exemplo visual:

[ ← Voltar ]   Nome do Template

[ Variáveis ] [ Documento ] [ IA ] [ Salvar ]

==================================================
BOTÃO VARIÁVEIS
==================================================

Ao clicar em "Variáveis":
abrir uma sidebar lateral direita.

A sidebar deve conter:

- campo de pesquisa
- variáveis agrupadas por categoria
- accordions expansíveis
- clique para inserir variável no cursor atual do editor

Estrutura exemplo:

AGÊNCIA
{{AGENCIA.NOME}}
{{AGENCIA.CNPJ}}

ARTISTA
{{ARTISTA.NOME}}
{{ARTISTA.CPF}}

MÚSICA
{{MUSICA.TITULO}}
{{MUSICA.ISRC}}

FINANCEIRO
{{ROYALTIES.PERCENTUAL}}
{{ADIANTAMENTO.VALOR}}

==================================================
COMPORTAMENTO DAS VARIÁVEIS
==================================================

Ao clicar em uma variável:

Inserir automaticamente no cursor do editor.

Exemplo:
{{ARTISTA.NOME}}

Se estiver usando TipTap:
usar insertContent.

Se estiver usando Lexical:
usar update + insertNodes.

A inserção deve funcionar sem perder foco do editor.

==================================================
BOTÃO DOCUMENTO
==================================================

Ao clicar em "Documento":
abrir uma sidebar lateral direita.

Essa sidebar deve conter:

SEÇÃO:
CONFIGURAÇÕES DO DOCUMENTO

Campos:

- Upload Cabeçalho
- Upload Rodapé

Opcional:
- mostrar em todas páginas
- margem superior
- margem inferior

==================================================
UPLOAD DE CABEÇALHO E RODAPÉ
==================================================

Implementar upload de imagem para:

- headerImage
- footerImage

Aceitar:
- PNG
- JPG
- WEBP

Criar preview visual imediato após upload.

Exemplo:

Cabeçalho carregado ✓
Rodapé carregado ✓
