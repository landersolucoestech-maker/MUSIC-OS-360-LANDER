# REFATORAÇÃO ESTRUTURAL COMPLETA — SISTEMA DE TEMPLATE DE CONTRATOS

## OBJETIVO

Refatorar toda a arquitetura de templates de contratos para suportar:

* múltiplas categorias de contratos;
* classificação inteligente por domínio;
* renderização dinâmica de partes envolvidas;
* integração com artistas;
* integração com CRM;
* escalabilidade futura;
* centralização das regras de negócio;
* eliminação de hardcodes frágeis.

A implementação atual está incorreta porque a regra de negócio está acoplada diretamente ao formulário:

```ts
const TIPO_ARTISTICO = "Contrato Artístico";
```

Essa abordagem deve ser completamente removida.

---

# PROBLEMA ATUAL

Hoje:

* o formulário decide a lógica;
* o tipo é comparado por string;
* apenas um contrato é considerado artístico;
* CRM está modelado como clientes;
* regras estão espalhadas;
* não existe domínio centralizado;
* não existe classificação estrutural.

Isso inviabiliza escalabilidade.

---

# ARQUITETURA CORRETA

A estrutura precisa ser separada em:

```txt
/contracts
  /constants
  /domain
  /mappers
  /hooks
  /types
  /utils
  /components
```

# ETAPA 3 — MAPEAR ORIGEM DAS PARTES

## CRIAR:

```txt
/modules/contracts/mappers/contract-party-origin.mapper.ts
```

---

# ADICIONAR:

```ts
import { CONTRACT_TYPES } from "../constants/contract-types";
import { ContractPartyOrigin } from "../domain/contract-party-origin";

const ARTIST_TYPES = [
  ...CONTRACT_TYPES.ARTISTICOS,
  ...CONTRACT_TYPES.SHOWS,
  ...CONTRACT_TYPES.MARCAS_PUBLICIDADE,
  "Parceria entre Artistas",
  "Colaboração Musical (Feat com estrutura contratual)",
];

export const getContractPartyOrigin = (
  contractType: string
): ContractPartyOrigin => {
  if (ARTIST_TYPES.includes(contractType)) {
    return "ARTIST";
  }

  const allCRMTypes = Object.values(CONTRACT_TYPES)
    .flat()
    .filter((type) => !ARTIST_TYPES.includes(type));

  if (allCRMTypes.includes(contractType)) {
    return "CRM";
  }

  return "NONE";
};
```
