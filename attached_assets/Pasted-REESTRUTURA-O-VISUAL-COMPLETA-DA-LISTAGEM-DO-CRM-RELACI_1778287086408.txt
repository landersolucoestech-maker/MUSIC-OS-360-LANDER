REESTRUTURAÇÃO VISUAL COMPLETA DA LISTAGEM DO CRM RELACIONAL

OBJETIVO:
Transformar completamente o visual e arquitetura da página CRM para um modelo moderno de CENTRAL DE RELACIONAMENTO OPERACIONAL MUSICAL.

IMPORTANTE:
O CRM NÃO é pipeline de vendas.
O CRM NÃO é página de leads.
O CRM NÃO é kanban.
O CRM NÃO deve parecer ERP legado.

A página CRM será exclusivamente uma BASE DE CONTATOS RELACIONAIS da operação musical.

Ela deve funcionar como:
- central institucional
- agenda corporativa inteligente
- relacionamento empresarial
- gestão operacional de contatos
- relacionamento entre gravadora, parceiros e fornecedores

A experiência visual deve transmitir:
- SaaS premium
- sistema enterprise musical
- software moderno
- operação profissional
- gestão corporativa musical

======================================================================
DIRETRIZ OBRIGATÓRIA
======================================================================

REMOVER COMPLETAMENTE:
- aspecto de tabela
- aparência de ERP antigo
- grids rígidos
- linhas excessivas
- separações horizontais fortes
- colunas tradicionais
- labels repetitivas:
  - NOME
  - CIDADE
  - RESPONSÁVEL
  - CONTRATOS

A página NÃO pode mais parecer:
- tabela administrativa
- sistema legado
- painel financeiro antigo
- CRM comercial genérico

======================================================================
ESTRUTURA NOVA OBRIGATÓRIA
======================================================================

SUBSTITUIR TOTALMENTE A LISTAGEM ATUAL POR:

SMART RELATIONSHIP CARDS

Cada contato deve ser exibido em formato CARD MODERNO HORIZONTAL.

======================================================================
ESTRUTURA VISUAL DOS CARDS
======================================================================

CADA CARD DEVE TER 4 BLOCOS:

1. IDENTIDADE
2. CONTEXTO OPERACIONAL
3. RELACIONAMENTO
4. AÇÕES

======================================================================
1. BLOCO IDENTIDADE
======================================================================

Este deve ser o bloco dominante visualmente.

EXIBIR:
- avatar/logo grande
- nome da empresa/pessoa
- tipo do contato
- cidade/estado
- email
- telefone

EXEMPLO VISUAL:

[LOGO]

Sony Music Brasil
Distribuidora • São Paulo/SP

📧 contato@sony.com
📞 (11) 3333-4444

REGRAS:
- nome deve possuir maior destaque visual
- email e telefone abaixo do nome
- tipografia hierárquica
- spacing moderno
- ícones minimalistas
- remover aparência textual crua

======================================================================
2. BLOCO CONTEXTO OPERACIONAL
======================================================================

EXIBIR:
- quantidade de contratos ativos
- quantidade de projetos vinculados
- quantidade de lançamentos relacionados
- última interação
- status operacional

EXEMPLO:

3 contratos ativos
12 lançamentos vinculados
Última interação: ontem

[ATIVO]
[ALTA PRIORIDADE]

REGRAS:
- badges modernos
- pills grandes
- ícones opcionais
- visual premium
- status bem destacado

======================================================================
3. BLOCO RELACIONAMENTO
======================================================================

EXIBIR:
- responsável interno
- departamento
- tags relacionais
- categoria operacional

EXEMPLO:

Responsável:
Carlos Henrique

Tags:
[Distribuição]
[Licenciamento]
[Major]
[Fornecedor]
[Editora]

REGRAS:
- tags modernas
- visual semelhante SaaS premium
- agrupamento inteligente
- não parecer etiquetas antigas

======================================================================
4. BLOCO AÇÕES
======================================================================

REMOVER menu escondido de 3 pontinhos.

SUBSTITUIR POR BOTÕES VISÍVEIS.

EXIBIR:
- Abrir
- Contratos
- Financeiro
- WhatsApp
- Email
- Histórico

REGRAS:
- botões compactos
- visual clean
- hover moderno
- ícones discretos
- alinhamento elegante
