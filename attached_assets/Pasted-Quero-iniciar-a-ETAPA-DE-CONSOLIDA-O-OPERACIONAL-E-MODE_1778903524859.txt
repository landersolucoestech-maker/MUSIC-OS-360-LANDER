Quero iniciar a ETAPA DE CONSOLIDAÇÃO OPERACIONAL E MODELAGEM DE DOMÍNIO do MUSIC OS 360.

IMPORTANTE:
Este projeto NÃO é um CRUD simples nem um MVP descartável.
Trata-se de um ERP operacional musical multi-tenant com dezenas de módulos interdependentes, RBAC, RLS, contratos, releases, catálogo, CRM, mídia, integrações e workflows críticos.

O objetivo desta etapa NÃO é adicionar features aleatórias.
O objetivo é consolidar o CORE DO DOMÍNIO, formalizar workflows operacionais, estabilizar invariantes e preparar a plataforma para escala real SaaS enterprise-grade.

Quero uma análise PROFUNDA de TODO o projeto atual antes de qualquer alteração.
