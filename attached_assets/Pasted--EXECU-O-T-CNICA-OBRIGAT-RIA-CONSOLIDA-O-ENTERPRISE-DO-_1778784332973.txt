TASK 2 — AUTH + TENANT FIX

━━━━━━━━━━━━━━━━━━━

PROBLEMA

TenantGuard NÃO popula:

request.tenantId
request.userId

Controllers usam:

req.tenantId
req.userId

mas recebem undefined.

Isso quebra tenancy silenciosamente.

━━━━━━━━━━━━━━━━━━━

EXECUTAR
Corrigir TenantGuard

Após validar tenant/member:

Adicionar:

request.tenantId = tenant.id
request.userId = auth.userId

━━━━━━━━━━━━━━━━━━━

Criar express.d.ts

Estender Express.Request com:

tenantId: string
userId: string
tenant: Tenant
currentMember: OrgMember

━━━━━━━━━━━━━━━━━━━

Remover req:any

Substituir TODOS:

@Request() req: any

por:

@Req() req: Request

━━━━━━━━━━━━━━━━━━━

Corrigir Clerk token refresh

REMOVER:

tryRefresh()

NÃO existe endpoint /auth/refresh válido com Clerk.

Implementar retry usando:

getToken({ skipCache: true })

Garantir retry único sem loop infinito.

━━━━━━━━━━━━━━━━━━━

RESULTADO OBRIGATÓRIO

Toda request autenticada DEVE possuir:

req.tenantId
req.userId

válidos.

Nenhum controller deve usar any.
