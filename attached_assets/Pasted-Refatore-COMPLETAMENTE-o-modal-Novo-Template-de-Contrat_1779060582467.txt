Refatore COMPLETAMENTE o modal "Novo Template de Contrato".

O modal atual está visualmente poluído, mal distribuído e com UX extremamente ultrapassada.
A estrutura baseada em blocos verticais gigantes ("Informações Básicas", "Cabeçalho e Rodapé", "Cláusulas") deixa o fluxo cansativo, desorganizado e pouco profissional.

O objetivo agora é transformar esse modal em uma experiência moderna baseada em ABAS (tabs), com navegação limpa, separação lógica e aparência premium.

==================================================
OBJETIVO DA REFATORAÇÃO
==================================================

Transformar o modal atual em:

- moderno
- organizado
- rápido de navegar
- visualmente limpo
- parecido com software SaaS profissional
- com experiência semelhante a:
  - Notion
  - Linear
  - Stripe Dashboard
  - Vercel
  - Google Docs

==================================================
NOVA ESTRUTURA
==================================================

O modal NÃO deve mais ser uma página vertical longa.

Deve virar:

- Header
- Tabs horizontais
- Conteúdo dinâmico por aba
- Footer fixo

==================================================
ESTRUTURA VISUAL
==================================================

MODAL:
- largura: 980px ~ 1100px
- altura máxima: 85vh
- bordas suaves
- fundo dark elegante
- spacing premium
- sem scroll externo desnecessário

==================================================
HEADER DO MODAL
==================================================

Topo fixo contendo:

ESQUERDA:
- título:
  "Novo Template de Contrato"

DIREITA:
- botão fechar

Abaixo do título:
subtítulo discreto:

"Crie templates reutilizáveis para geração automática de contratos."

==================================================
ABAS (TABS)
==================================================

Adicionar tabs horizontais logo abaixo do header.

Estrutura:

[ Geral ]
[ Documento ]
[ Conteúdo ]
[ Variáveis ]

Tabs modernas:
- estilo pills
- hover suave
- active state destacado
- animação sutil

==================================================
ABA: GERAL
==================================================

Essa aba contém APENAS:

- Nome do Template
- Tipo de Contrato

Layout:
2 colunas responsivas.

Exemplo:

--------------------------------
Nome do Template | Tipo
--------------------------------

Nada além disso.

==================================================
ABA: DOCUMENTO
==================================================

Mover TODO cabeçalho e rodapé para cá.

Estrutura:

CARD:
"Identidade Visual do Documento"

2 uploads lado a lado:

[ Upload Cabeçalho ]
[ Upload Rodapé ]

Cada upload deve ter:
- ícone
- estado vazio elegante
- preview após upload
- botão trocar imagem

IMPORTANTE:
o visual atual está horrível.
Precisa parecer upload premium.

Inspirar em:
- upload do Stripe
- upload do Notion
- upload do Canva

- hover state

==================================================

REMOVER completamente:
- sistema antigo de cláusulas

Placeholder:

==================================================
