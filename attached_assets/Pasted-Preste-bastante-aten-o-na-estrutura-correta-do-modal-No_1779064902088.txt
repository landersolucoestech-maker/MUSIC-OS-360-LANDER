Preste bastante atenção na estrutura correta do modal “Novo Template de Contrato”.

O modal precisa ser reorganizado de forma profissional e lógica, mantendo uma experiência limpa e funcional.

A estrutura correta deve ser a seguinte:

==================================================
ABA: TEMPLATE
==================================================

Essa será a aba principal do modal.

Ela deve conter:

--------------------------------------------------
SEÇÃO: INFORMAÇÕES BÁSICAS
--------------------------------------------------

Campos:
- Nome do Template
- Categoria do Template

Layout em 2 colunas.

--------------------------------------------------
SEÇÃO: CABEÇALHO E RODAPÉ
--------------------------------------------------

Adicionar uploads de imagem para:

- Cabeçalho
- Rodapé

Os uploads devem ficar lado a lado.

Cada upload precisa ter:
- estado vazio elegante
- preview da imagem
- substituir imagem
- remover imagem

--------------------------------------------------
SEÇÃO: EDITOR DE CLÁUSULAS
--------------------------------------------------

Abaixo do cabeçalho/rodapé deve existir o editor principal do contrato.

IMPORTANTE:
NÃO usar mais múltiplos textareas separados por cláusula.

Deve existir:
- um editor contínuo
- estilo documento
- área ampla
- experiência semelhante a Word/Docs

Placeholder:
“Escreva o conteúdo do contrato...”

--------------------------------------------------
PAINEL LATERAL DIREITO
--------------------------------------------------

Ao lado do editor manter um painel lateral fixo contendo:

- legenda/referência das variáveis
- categorias organizadas
- placeholders disponíveis

Exemplo:

AGÊNCIA
{{AGENCIA.NOME}}
{{AGENCIA.CNPJ}}

ARTISTA
{{ARTISTA.NOME}}

FINANCEIRO
{{ROYALTIES.PERCENTUAL}}

Esse painel lateral deve permanecer visível dentro da aba principal.

==================================================
ABA: VARIÁVEIS
==================================================

Criar uma aba separada chamada:

“Variáveis”

Essa aba será responsável pelo gerenciamento completo das variáveis.

Ela deve conter:
- listagem
- busca
- criação
- edição
- importação
- exportação

Visual semelhante ao CRUD moderno já existente no sistema.

==================================================
ABA: PREVIEW
==================================================

Criar uma aba chamada:

“Preview”

Essa aba deve renderizar uma visualização real do template.

Exibir:
- cabeçalho
- conteúdo do contrato
- rodapé

A visualização deve simular:
- folha A4
- documento real
- espaçamento correto
- aparência de PDF/Word

==================================================
ESTRUTURA FINAL DO MODAL
==================================================

Tabs no topo:

[ Template ]
[ Variáveis ]
[ Preview ]

==================================================
OBJETIVO
==================================================

O modal precisa transmitir aparência de:
- editor profissional
- sistema jurídico moderno
- ferramenta enterprise

A experiência deve ser:
- organizada
- limpa
- intuitiva
- visualmente moderna
- sem aparência de CRUD antigo
- sem layout vertical desorganizado
