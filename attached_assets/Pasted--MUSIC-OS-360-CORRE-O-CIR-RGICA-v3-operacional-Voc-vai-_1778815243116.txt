## PROBLEMA 2 — `.replit`: seção `[deployment]` aponta para arquivo inexistente

**Arquivo:** `.replit`

**Problema atual:**
```toml
[deployment]
deploymentTarget = "static"
run = ["node", "./dist/index.cjs"]
build = ["npm", "run", "build"]
publicDir = "dist"
```

`deploymentTarget = "static"` é para sites sem servidor. O projeto tem NestJS na porta 3001. O arquivo `./dist/index.cjs` não existe — o NestJS compila para `apps/api/dist/main.js`.

**Correção — substituir apenas o bloco `[deployment]`:**
```toml
[deployment]
deploymentTarget = "cloudrun"
build = ["npm", "run", "build"]
run = ["sh", "-c", "node apps/api/dist/main.js"]
```

O resto do `.replit` permanece **idêntico**. Não mexa nos workflows, ports, userenv, postMerge ou qualquer outra seção.

## PROBLEMA 3 — `.replit`: `VITE_CLERK_PUBLISHABLE_KEY` faltando no `[userenv.shared]`

**Arquivo:** `.replit`

**Problema:** O `[userenv.shared]` já tem `VITE_API_URL`, `VITE_USE_MOCK`, etc., mas não tem `VITE_CLERK_PUBLISHABLE_KEY`. Quando `VITE_USE_MOCK=false` for ativado para usar o backend real, o `@clerk/clerk-react` vai falhar sem essa variável.

**Correção — adicionar UMA linha ao `[userenv.shared]` existente:**
```toml
[userenv.shared]
VITE_API_URL = "http://localhost:3001/api/v1"
VITE_USE_MOCK = "true"
VITE_MOCK_MODE = "true"
VITE_SENTRY_DSN = ""
VITE_POSTHOG_KEY = ""
VITE_APP_NAME = "MUSIC OS 360"
VITE_CLERK_PUBLISHABLE_KEY = ""
```

A linha `VITE_CLERK_PUBLISHABLE_KEY = ""` é adicionada. O valor vazio será preenchido pelo usuário nos Replit Secrets depois.
