# Push forçado para GitHub

## Objetivo
Atualizar o repositório GitHub com o código atual do Replit, sobrescrevendo o histórico remoto.

## Steps
1. Configurar remote origin: `git remote set-url origin https://oauth2:<TOKEN>@github.com/landersolucoestech-maker/MUSIC-OS-360.git`
2. Executar: `git push --force origin main`
